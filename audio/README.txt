DAILY PROPHET — AMBIENT MUSIC
=============================

The Daily Prophet theme has a music control (🎵, top-right of the newspaper).
It looks for a track at:

    public/audio/prophet-theme.mp3   (preferred)
    public/audio/prophet-theme.ogg   (optional fallback)

Drop a file with EXACTLY that name here and it will play (looped, fades in)
the moment you open the Daily Prophet, and stop when you leave.

IMPORTANT — copyright:
- Do NOT use the actual Harry Potter / "Hedwig's Theme" soundtrack. It is
  copyrighted by Warner Bros. / John Williams and must not be published.
- Use a ROYALTY-FREE / CC0 "magical / fantasy / orchestral" track instead.
  Good free sources: Pixabay Music, YouTube Audio Library, Free Music Archive,
  Incompetech (Kevin MacLeod, with attribution). Search "magical fantasy loop".

Then just refresh the page — no code changes needed.
